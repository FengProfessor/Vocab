## B. Listening — protocol + raw → band

### Protocol
1. Chọn **Test 1** (hoặc bất kỳ full test chưa làm) trong Cambridge.
2. Nghe **1 lần**, điền answer sheet / typed list 1–40.
3. Chấm bằng answer key. **Spelling** sai = 0 (như thi thật).
4. Ghi: raw /40 + band (bảng dưới).

### Raw → Band (Academic, xấp xỉ — Cambridge có thể lệch ±1 theo đề)

| Raw /40 | Band ước |
|---------|----------|
| 16–17 | 5.0 |
| 18–22 | 5.5 |
| 23–25 | 6.0 |
| 26–29 | 6.5 |
| **30–32** | **7.0** |
| **33–34** | **7.5** |
| **35–36** | **8.0** |
| 37–38 | 8.5 |
| 39–40 | 9.0 |

### Error log Listening (bắt buộc 5 dòng)
| # | Câu | Đáp án đúng | Bạn viết | Loại lỗi |
|---|-----|-------------|----------|----------|
| | | | | spelling / distractor / miss number / synonym / lost place |

**Loại lỗi ưu tiên track:** distractor (nghe thấy A rồi đổi sang B), plural/spelling, số/địa chỉ, Section 3–4 paraphrase.

## C. Reading Academic — protocol + raw → band

### Protocol
1. Full 3 passages, **60 phút**, không nghỉ giữa.
2. Áp dụng thử **15–20–25** (P1/P2/P3); ghi giờ thật từng passage.
3. Chấm key. TFNG/YNNG sai = 0 (không nửa điểm).

### Raw → Band (Academic, xấp xỉ)

| Raw /40 | Band ước |
|---------|----------|
| 15–18 | 5.0 |
| 19–22 | 5.5 |
| 23–26 | 6.0 |
| 27–29 | 6.5 |
| **30–32** | **7.0** |
| **33–34** | **7.5** |
| **35–36** | **8.0** |
| 37–38 | 8.5 |
| 39–40 | 9.0 |

### Error taxonomy (mỗi sai → 1 tag)
- `PARAPHRASE` — không nhận synonym/paraphrase
- `TFNG_OVERTHINK` — đoán ngoài text
- `HEADING` — matching headings
- `TIME` — biết nhưng hết giờ / đoán
- `DETAIL` — bỏ qua qualifier (only, mainly, some…)

Ghi: **số lỗi theo tag** + phút thực tế P1/P2/P3.

## D. Writing — prompts diagnostic (1 set)

> **Không** mở model essay trước. Typed, timed.  
> Font 12, double-space optional. Đếm từ cuối giờ.

### Task 1 (20 phút, ≥150 words) — Academic

**The chart below shows the percentage of remote workers in four countries in 2015 and 2025.**  
*(Nếu không có chart: dùng bảng số liệu sau như “table” Task 1.)*

| Country | 2015 | 2025 |
|---------|------|------|
| Vietnam | 8% | 27% |
| Japan | 12% | 22% |
| Germany | 15% | 31% |
| USA | 20% | 38% |

**Prompt:**  
*Summarise the information by selecting and reporting the main features, and make comparisons where relevant. Write at least 150 words.*

### Task 2 (40 phút, ≥250 words)

**Prompt:**  
*Some people believe that artificial intelligence will create more jobs than it destroys. Others think AI will cause widespread unemployment.*

*Discuss both views and give your own opinion.*

*Give reasons for your answer and include any relevant examples from your own knowledge or experience. Write at least 250 words.*

## E. Writing — rubric tự chấm tạm (TR / CC / LR / GRA)

### Cách chấm (nghiêm)
1. Đọc **public band descriptors** Writing Task 1 + Task 2 (British Council PDF) nếu có.
2. Mỗi tiêu chí chọn **1 band** (5 / 5.5 / 6 / 6.5 / 7 / 7.5 / 8).  
   - Nếu giữa 2 mức → **lấy thấp hơn** (bias chống tự ảo).
3. **Writing overall** = trung bình 4 tiêu chí Task 2 (Task 1 chỉ log phụ; exam: T2 nặng hơn T1).  
   Diagnostic đơn giản: chấm **Task 2 đủ 4 tiêu chí**; Task 1 tick checklist riêng.

### Task 2 — checklist nhanh → band gợi ý

#### TR — Task Response
| Tick | Mô tả | Band gợi ý nếu match |
|------|--------|----------------------|
| [ ] | Trả lời **cả 2 views + opinion** rõ | ≥6 |
| [ ] | Position nhất quán suốt bài | ≥6.5 |
| [ ] | Ý chính **được mở rộng** (why + example), không list bullet | ≥7 |
| [ ] | Mọi phần prompt cover **đều** (không body 1 dày body 2 mỏng) | ≥7 |
| [ ] | Extension sâu, example cụ thể, không mơ hồ “many people say” | ≥7.5–8 |

**Tự hỏi 1 câu:** *Mỗi body có claim → because → example → so what không?*  
- Không → TR ≤6.5  
- Có nhưng example generic → TR ~6.5–7  
- Có + logic chặt → TR ≥7

#### CC — Coherence & Cohesion
| Tick | Mô tả | Band |
|------|--------|------|
| [ ] | 4 đoạn rõ (intro / body / body / conclusion) | ≥6 |
| [ ] | Mỗi đoạn 1 central topic | ≥6.5 |
| [ ] | Progression logic (reader không “nhảy”) | ≥7 |
| [ ] | Cohesive devices **đa dạng** nhưng **không spam** Firstly/Moreover | ≥7 |
| [ ] | Reference chains (*this shift / these measures*) tự nhiên | ≥7.5–8 |

**Penalty cứng:** mỗi câu mở bằng linker công thức → CC tối đa **6.0–6.5**.

#### LR — Lexical Resource
| Tick | Mô tả | Band |
|------|--------|------|
| [ ] | Đủ từ thảo luận topic (AI, employment) | ≥6 |
| [ ] | Có collocation đúng (*create jobs, widespread unemployment, automate routine tasks*) | ≥6.5–7 |
| [ ] | Ít collocation lỗi / word formation | ≥7 |
| [ ] | Precise, flexible; rare unnatural “big word” | ≥7.5–8 |

**Penalty:** dịch word-by-word / “do a research” / “make a progress” → LR ≤6.5.

#### GRA — Grammatical Range & Accuracy
| Tick | Mô tả | Band |
|------|--------|------|
| [ ] | Mix simple + complex (if / which / although) | ≥6 |
| [ ] | Nhiều câu error-free; lỗi không che nghĩa | ≥6.5–7 |
| [ ] | Complex linh hoạt; lỗi lẻ | ≥7 |
| [ ] | Đa số câu sạch; control punctuation | ≥7.5–8 |

**Kill-list VN — mỗi lỗi lặp ≥3 lần = systematic (hạ band):**
- [ ] Bỏ **a/an/the**
- [ ] S-V agreement / thiếu -s
- [ ] Run-on / comma splice
- [ ] Tense nhảy lung tung
- [ ] Relative clause vỡ

### Task 1 — checklist (pass/fail Band 7 trajectory)

| # | Checklist | Yes/No |
|---|-----------|--------|
| 1 | Paraphrase intro (không copy prompt y nguyên) | |
| 2 | **Overview** rõ 2–3 main features, **không** nhét số vào overview | |
| 3 | Group data logic (không list từng cell) | |
| 4 | So sánh (highest/lowest/change) | |

- Overview tốt + detail group → trajectory **7+**.

## F. Speaking — full interview script (record 1 take)

### Setup
- Ngồi yên, mic 20–30cm.
- Timer visible.
- **Không** note Part 1/3; Part 2 được 1′ note trên giấy.
- File audio: `week0-speaking-YYYYMMDD.m4a`

### Part 1 (~4–5 phút) — examiner script

*Good morning. My name is Alex. Can you tell me your full name, please?*  
*Thank you. Can I see your identification?*  
*Now, in this first part, I’d like to ask you some questions about yourself.*

**Home / work**
1. Do you work or are you a student?  
2. What do you do in your job / studies?  
3. What do you find most interesting about your work?  
4. Do you prefer working in the morning or in the evening? Why?

**Technology**
5. How often do you use technology in your daily life?  
6. What piece of technology is most useful for you?  
7. Have the ways people use phones changed in your country?  

**Free time**
8. What do you usually do in your free time?  
9. Do you prefer free time alone or with other people?  
10. Did you have the same hobbies when you were a child?

### Part 2 (1′ prepare + 1–2′ speak)

**Candidate task card:**

> **Describe a skill you would like to learn.**  
> You should say:  
> - what the skill is  
> - how you would learn it  
> - how long it might take  
> - and explain why you want to learn this skill.

*(After 1–2′ monologue)*  
*Do you think many people want to learn this skill?* (1 follow-up ngắn)

### Part 3 (~4–5 phút) — abstract

**Skills & work**
1. What skills are most important for young people entering the job market today?  
2. Do you think schools should focus more on practical skills or academic knowledge? Why?  
3. How might automation change the skills people need in the next 20 years?

**Learning**
4. Why do some adults find it hard to learn new skills later in life?  
5. Is it better to learn deeply from one mentor or from many online sources?  
6. Should governments pay for workers to retrain when industries change?

**Stop recording.** Total ~11–14′.

## G. Speaking — rubric tự chấm tạm (FC / LR / GRA / PR)

### Cách chấm
1. Nghe **full audio 1 lần** không pause (cảm nhận fluency).  
2. Nghe lần 2: note lỗi theo 4 tiêu chí.  
3. Mỗi tiêu chí lấy band **thấp nếu nghi**.  
4. Overall S = avg 4 tiêu chí.

### FC — Fluency & Coherence
| Quan sát | Band gợi ý |
|----------|------------|
| Trả lời ngắn, ngắt quãng, digression | ≤5.5 |
| Nói được độ dài nhưng hay lặp / self-correct / “um” dài | 6.0 |
| Mạch ổn Part 1–2; Part 3 còn gượng | 6.5 |
| Mở rộng Part 3 có structure (point→explain→example); ít hesitation tìm grammar | **7.0** |
| Discussion mượt, discourse markers tự nhiên | 7.5–8 |

**Checklist Part 3 extension**
- [ ] Có **Point** rõ trong 1 câu đầu  
- [ ] Có **Explain** (why/how)  
- [ ] Có **Evidence** (VN / work / hypothetical)  
- [ ] Có **Link** (consequence / other side)  
Thiếu 2+ mục → FC ≤6.5

### LR — Lexical
| Quan sát | Band |
|----------|------|
| Vocab basic, paraphrase kém | ≤5.5–6 |
| Đủ topic; ít collocation | 6.0–6.5 |
| Linh hoạt, paraphrase được, ít collocation sai | **7.0** |
| Precise + idiomatic hiếm lỗi | 7.5–8 |

### GRA — Grammar
| Quan sát | Band |
|----------|------|
| Câu đơn chiếm ưu thế; lỗi che nghĩa | ≤5.5–6 |
| Complex có nhưng lỗi systematic (article, -s) | 6.0–6.5 |
| Complex ổn định; phần lớn câu sạch | **7.0** |
| Range rộng, lỗi lẻ | 7.5–8 |

### PR — Pronunciation
| Quan sát | Band |
|----------|------|
| Khó hiểu nhiều chỗ; stress sai liên tục | ≤5.5 |
| Hiểu được nhưng flat / drop final sound nhiều | 6.0 |
| Rõ overall; vẫn drop /s/ /t/ hoặc cluster thỉnh thoảng | 6.5 |
| Rõ + chunking + stress content words; final C ổn | **7.0** |
| Nuanced intonation, dễ follow | 7.5–8 |

### Kill-list nghe audio (đếm)
| Lỗi | Số lần ~ | Systematic? (≥5) |
|-----|----------|------------------|
| Drop final /s z t d/ | | Y/N |
| Cluster simplify | | Y/N |
| Flat intonation (không stress key word) | | Y/N |
| Long silent search | | Y/N |
| Linker spam (firstly/secondly…) | | Y/N |

Systematic **Y** trên PR hoặc GRA → band tiêu chí đó **không** vượt 6.5 trừ khi đã fix nghe rõ.
