# Buổi 1: Làm Quen & Chào Hỏi Vui Vẻ

---

### TRÒ CHƠI 1: LÀM QUEN VỚI BẠN MỚI

Hãy cùng lắng nghe bạn Nam giới thiệu nhé:

```text
       ┌────────────────────────┐
       │      (•‿•)   NAM       │
       │      Tuổi: 12          │
       │                        │
       │    "Hello!             │
       │     My name is Nam.    │
       │     What's your name?" │
       └────────────────────────┘
```

---

### TRÒ CHƠI 2: KHỐI TỪ KỲ DIỆU

Hãy cùng ghép các khối từ để tạo câu giới thiệu của riêng con:

| Khối bắt đầu | Tên của con |
|---|---|
| **My name is** | `[  Minh  ]` &nbsp;&nbsp; `[  Nam  ]` &nbsp;&nbsp; `[  Lan  ]` &nbsp;&nbsp; `[  ...............  ]` |

| Khối bắt đầu | Tuổi của con |
|---|---|
| **I'm** | `[  11  ]` &nbsp;&nbsp; `[  12  ]` |

---

### TRÒ CHƠI 3: TÌM HÌNH NHANH MẮT

Thầy/cô sẽ nói một từ hoặc giơ một thẻ chữ bí mật. Con hãy chỉ thật nhanh vào bức tranh tương ứng nhé!

```text
    ┌──────────────┐     ┌──────────────┐
    │  [ TRANH 1 ] │     │  [ TRANH 2 ] │
    │     Bút bi   │     │    Quyển     │
    │              │     │     sách     │
    └──────────────┘     └──────────────┘

    ┌──────────────┐     ┌──────────────┐
    │  [ TRANH 3 ] │     │  [ TRANH 4 ] │
    │     Cặp/     │     │     Uống     │
    │     Balo     │     │     nước     │
    └──────────────┘     └──────────────┘
```

---

### TRÒ CHƠI 4: CHUYỀN BÓNG TÍ TÁCH

Khi nhận được quả bóng từ thầy/cô, con hãy nói một câu thật vui:

* **Con**: *"Hello! My name is ............... What's your name?"*
* **Thầy/Cô**: *"Hello! My name is ............... Nice to meet you!"*

---

### CON CẢM THẤY BUỔI HỌC HÔM NAY THẾ NÀO?

Hãy khoanh tròn vào biểu tượng con thấy đúng nhất nhé:

```text
   [ 🙂 Dễ & Vui ]       [ 😐 Hơi khó chút ]       [ 🙁 Khó quá ]       [ 🛑 Con muốn nghỉ ]
```
