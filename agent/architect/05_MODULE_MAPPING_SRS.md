## Các Điểm Chú Ý Khi Hiện Thực Hóa (Implementation Guidelines)

1. **Tuân Thủ Tuyệt Đối Nguyên Lý SOLID, 1 File = 1 Class & 100% Comment Tiếng Anh**:
   * Mỗi Entity, Enum (`CertLevel`, ...), Command, Query, Handler, Validator, DTO, Configuration, NUnit Test Class, và React Component đều phải nằm trên **1 file độc lập** trùng tên với class/type đó.
   * Toàn bộ comment trong mã nguồn (`/// <summary>` và `// ...`) bắt buộc viết bằng **tiếng Anh**.
2. **Mọi Phản Hồi API Đều Có `StatusCode` Trong `ApiResponse<T>`**:
   * Đảm bảo trả về `statusCode` (`200`, `201`, `400`, `401`, `403`, `404`, `429`, `500`) nhất quán trong mọi response JSON.
3. **Chiến Lược Cache 2 Giai Đoạn Có Chọn Lọc (Selective Multi-Level Caching)**:
   * **Giai đoạn 1 (Hiện tại)**: Đăng ký `NoOpCacheService` cho `ICacheService` — chưa bật cache, nhưng toàn bộ kiến trúc `ICacheService` và `CachingBehavior<TRequest, TResponse>` (ràng buộc `where TRequest : ICacheableQuery`) đã sẵn sàng.
   * **Giai đoạn 2 (Khi mở rộng quy mô)**: Chuyển cấu hình sang `HybridMultiLevelCacheService` (**L1 Local `IMemoryCache` + L2 `Redis`**) mà không phải sửa code nghiệp vụ. Chỉ các Query danh mục dùng chung cài đặt `ICacheableQuery` mới được cache; mọi dữ liệu lịch sử học tập, SRS Due Queue, đơn hàng và tiến độ cá nhân đều đọc trực tiếp từ Database.
4. **Phân Quyền Chặt Chẽ Cho Giáo Viên (`[Authorize(Policy = "RequireTeacher")]`)**:
   * Toàn bộ các chức năng quản lý lớp học (`classrooms`), danh sách học sinh (`enrollments`), thống kê chuyên cần VMS/LCS (`student_daily_stats`), ngân hàng từ vựng/ngữ pháp/bài đọc của lớp và ghi nhận đánh giá phát âm (`evidence_source = 'TEACHER'`) bắt buộc kiểm tra policy `RequireTeacher` kèm xác thực quyền sở hữu lớp (`classroom.TeacherId == currentUser.UserId`).
5. **Phối Hợp Nhịp Nhàng Giữa SSR (SEO & Login) Và React SPA**:
   * Trang chủ (`/`, `/landing`) và trang đăng nhập (`/auth/login`) luôn được render Server-Side từ `.NET 10`.
   * Sau khi đăng nhập thành công trên Server (cấp JWT Access Token **15 phút** + Refresh Token **30 ngày**), người dùng mới được chuyển tiếp vào ứng dụng React SPA (`/app/*`) với đầy đủ thông tin phiên đăng nhập.
6. **Kiểm Thử Nghiệp Vụ Bằng NUnit**:
   * Mọi thuật toán và quy tắc nghiệp vụ cốt lõi phải có bài test NUnit tương ứng trong `tests/LingoPro.Domain.UnitTests` và `tests/LingoPro.Application.UnitTests`.
